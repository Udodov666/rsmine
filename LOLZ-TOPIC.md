Готовый BBCode для вставки в описание темы. Бинарных сборок и ссылок на Releases больше нет — только инструкция по сборке из исходников.

```bbcode
[SIZE=6][B][COLOR=rgb(16, 164, 90)]RSMine [/COLOR]— бесплатная донат-панель[/B][/SIZE]
[SIZE=6][B]и алерты для OBS, без подписок.[/B][/SIZE]

[SIZE=4]Сайт: [URL='https://rsmine.ru']rsmine.ru[/URL][/SIZE]
[SIZE=4]Приложение для Windows: [URL='https://github.com/Udodov666/rsmine-desktop#сборка-из-исходников']инструкция по сборке[/URL] — откройте репозиторий, соберите и запустите.[/SIZE]

[SIZE=3][I][COLOR=rgb(127, 127, 127)]LZT-токен хранится локально в приложении и используется [/COLOR][/I][/SIZE]
[SIZE=3][COLOR=rgb(127, 127, 127)][I]для запросов к LZT API — передавать его серверам RSMine не нужно.[/I][/COLOR][/SIZE]


[B]Что умеет RSMine[/B]
[spoiler=align=left]
[LIST]
[*]Страница доната с пресетами сумм, ником, сообщением, озвучкой и эффектами.
[*]Конструктор алертов: медиа, заголовок, цвет, размер, скругления и анимация появления.
[*]Оверлей для OBS — один источник «Браузер».
[*]История донатов, цель сбора и статистика.
[*]Тест-донаты без денег — проверка алерта до стрима.
[*]Готовые медиа для алертов и 9 русских голосов Cartesia.
[/LIST][/spoiler]

[B]Как это работает[/B]
[spoiler=align=left]Сайт и панель управления работают на Vite + React + TypeScript. Фронтенд размещён на [URL='https://pages.cloudflare.com']Cloudflare Pages[/URL], серверный API — на Cloudflare Workers.

Десктоп-приложение связывает панель со стримом: работает с LZT Market, озвучкой Cartesia и оверлеем для OBS.

LZT-токен хранится на вашем компьютере в защищённом хранилище через Windows DPAPI. Приложение использует его для обращений к LZT API, но не передаёт серверам RSMine.[/spoiler]

[B]Установка и подключение[/B]
[spoiler=align=left]
[LIST=1]
[*]Откройте [URL='https://rsmine.ru']rsmine.ru[/URL] и войдите через Twitch.
[*]Соберите и запустите [URL='https://github.com/Udodov666/rsmine-desktop#сборка-из-исходников']приложение RSMine[/URL] из исходников — в README есть пошаговая инструкция.
[*]В приложении укажите свой slug, App Secret из настроек сайта, LZT API-токен и Merchant ID. Для нейроозвучки можно также указать ключ Cartesia.
[*]В панели откройте «Подключение OBS» и скопируйте ссылку на оверлей.
[*]В OBS добавьте источник «Браузер», вставьте ссылку и укажите размер 1920×1080.
[*]Отправьте тест-донат и проверьте алерт перед стримом.
[/LIST]

Требования: Windows 10/11, 64-bit. Готовых бинарных сборок не публикуется — приложение собирается самостоятельно по инструкции на GitHub.[/spoiler]

[B]Демо без входа[/B]
[spoiler=align=left]
[LIST]
[*]Сайт: [URL='https://rsmine.ru']rsmine.ru[/URL]
[*]Публичная страница доната: [URL='https://rsmine.ru/#/d/demo']открыть демо[/URL]
[*]Конструктор и превью алерта: [URL='https://rsmine.ru/#/landing-figma']открыть лендинг[/URL] — прокрутите вниз.
[/LIST]

Тестовые донаты нужны для проверки интерфейса и алертов, деньги для них не требуются.[/spoiler]

[spoiler=align=left]Сайт, панель управления, API и десктоп-приложение доступны с открытым исходным кодом. Лицензия — MIT.
```
